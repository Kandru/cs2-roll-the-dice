Roll The Dice is a hilarious and chaotic game mode plugin for Counter-Strike 2 that adds an element of unpredictable fun to every round. Players can use the `!rtd` command to roll a virtual dice and receive a random effect that can either give them a significant advantage or create amusing challenges. From turning into a giant chicken to becoming invisible, gaining superhuman speed, or being cursed with terrible aim, every dice roll brings excitement and laughter to the server.

This plugin transforms the traditional competitive nature of Counter-Strike 2 into a party-like atmosphere where anything can happen. Whether you're boosting your health, spawning an army of chickens as your loyal followers, or finding yourself stuck with vegetables instead of grenades, Roll The Dice ensures that no two rounds are ever the same. The effects are temporary and reset each round, keeping the gameplay fresh and encouraging players to take risks and embrace the chaos.

> [!TIP]
> This plug-in is highly configurable. In case you're missing something you want to be able to change create an GitHub Issue.

## Plugin Installation

1. Download and extract the latest release from the [GitHub releases page](https://github.com/Kandru/cs2-roll-the-dice/releases/).
2. Move the "RollTheDice" folder to the `/addons/counterstrikesharp/plugins/` directory of your gameserver.
3. If you do NOT use german or english please copy the en.json in the *lang*-Folder to your language country code and edit accordingly.
4. Restart the server.

## Plugin Update

Simply overwrite all plugin files and they will be reloaded automatically or just use the [Update Manager](https://github.com/Kandru/cs2-update-manager/) itself for an easy automatic or manual update by using the *um update RollTheDice* command.

## Commands

### !dice / !rtd / !rollthedice

This command triggers the dice for a player. To activate the dice with a button paste the following to the client console:

```
bind "o" rtd
```

Each player can run `!rtd` / `!dice` (with or without `auto` / `info`) once every 0.5 seconds; faster repeats, e.g. from a console bind, are ignored.

### !dice auto

Enables or disables the automatic !rtd mode (will roll the dice automatically on spawn depending on the settings made inside your configuration).

### !dice info

Opens (or closes) the info menu - a mouse-driven Panorama window in the player's language (German or English). The reel footer shows this command on every roll. Every list is a single scrollable page. Tabs:

- **This round** (start page): every dice rolled this round, CT and T side by side, alive players first, with the dice; dead players are framed red and greyed out.
- **My dice**: the player's last 12 dice (kept while the plugin is loaded).
- **Perks**: every dice enabled on the current map with its category (very good / good / neutral / bad / very bad) and a short description. Filter by category (`++ + ± – ––`), sort by name or type, and search with `!dice info <text>` (for example `!dice info gravity`); the search is shown in the menu and can be cleared there.
- **Commands**: the chat commands; admins (`@rollthedice/admin`) also see the admin chat commands.
- **Admin** (only for `@rollthedice/admin`): lock rolling for everyone or single players, roll for one or all players (random or a chosen perk) and choose which perks a roll can draw - five category switches plus every perk on its own (default: all). Saved at once in the config section `admin`; the permission is checked on every click.
- **Settings**: auto roll on/off (same as `!dice auto`; locked when the server forces or disables it) and the language (Deutsch / English). The language is saved per player (`player_configs`) and set as the CounterStrikeSharp player language, so chat messages, the reel and the menu follow it.

The menu closes on the close button, the same command, the player's death and round start. Requires the workshop addon (`info_v5` layout; `info_v4` stays in the addon for older plugin versions).

### !givedice (@rollthedice/admin)
This admin command allows administrators to force dice rolls for players (including bots, for debugging). Bots do not roll on their own. Requires the @rollthedice/admin permission. Dice names correspond to the class names in the [dices folder](src/dices/) and are case-insensitive; ambiguous matches list the options instead of guessing.

```
// list enabled dice
!givedice

// roll randomly for a player (or bot)
!givedice PlayerName

// roll a specific dice for everyone (humans and bots)
!givedice * glow

// roll a specific dice for a player (or bot)
!givedice PlayerName glow
```

### rollthedice (Server Console Only)

Ability to run sub-commands:

#### reload

Reloads the configuration.

#### disable

Disables the !rtd command instantly and remembers this state.

#### enable

Enables the !rtd command instantly and remembers this state.

#### createmapconfig

Creates a map-specific configuration for the current map in the config file from the global defaults for further editing.

#### deletemapconfig

Deletes a map-specific configuration for the currvent map in the config file and loads the global defaults.

### enabled

Enables or disables the plugin globally.

### debug

Enables debug mode for development and troubleshooting.

### allow_rtd_during_warmup

Allows players to use !rtd during warmup rounds.

### trigger

Controls when dice are automatically rolled:
- **event**: When to trigger auto-roll (`RoundStart` or `RoundFreezeEnd`)
- **force_all_players**: Forces all players to roll dice at the given event
- **allow_player_auto_rtd**: Allows players to use their automatic dice roll they can activate via `!rtd auto`
- **roll_the_dice_every_x_seconds**: Automatically rolls dice every X seconds (0 = disabled)

### cooldown_rounds

Number of rounds a player must wait before using !rtd again. Use this OR cooldown_seconds, not both (0 = disabled).

### cooldown_seconds

Number of seconds a player must wait before using !rtd again. Use this OR cooldown_rounds, not both (0 = disabled).

### price_to_dice

Money it costs to roll the dice. It is charged only when the roll actually happens (alive, no cooldown, not already rolled).

### allow_dice_after_respawn

Allows players to use `!rtd` again after respawning in the same round.

### reel

Slot-machine reel shown in the screen centre (below the crosshair) whenever a dice is rolled: via `!rtd`, the automatic roll and `!givedice`. It is purely visual - the dice is chosen and applied exactly as before, the reel only shows the result. While it spins, the player's center message is replaced by the reel, and the banner, the chat line and `dice_sound` follow when it stops. Spectators watching the player see the reel too; bots never get one. Requires `notify_player_via_panorama` and the workshop addon.

- **enabled**: Shows the reel (`false` = notifications as before).
- **spin_seconds**: Spin duration, 1.0 - 5.0 in steps of 0.5.
- **hold_seconds**: How long the result stays before the reel fades out, 0.5 - 5.0 in steps of 0.5.
- **tick_sound**: Played for each row passing the win line (sound event or `sounds/...` path, empty = off). A `sounds/...` path may only contain letters, digits and `_ - . /` (it is played with the client command `play`); other paths are ignored with a console message.
- **tones**: Category per dice class, shown on the reel and in the info menu: `very_good`, `good` (▲), `neutral` (◆), `bad`, `very_bad` (▼). Dices missing here use the built-in default.
- **tones_version**: Written by the plugin. Configs from before the five categories list every dice with its old tone; on the first start the dices that moved to `very_good` / `very_bad` follow the move if they still have their old tone, then the version is set to 2.

### admin

Set from the admin tab of `!dice info` and saved at once; can also be edited here.

- **rolls_locked**: Nobody can roll on their own (`!rtd`, auto roll, timed rolls). Admins can still hand out dices.
- **locked_players**: SteamID64s that cannot roll on their own.
- **disabled_categories**: Categories a roll never draws (`very_good`, `good`, `neutral`, `bad`, `very_bad`).
- **disabled_dices**: Dice class names a roll never draws. A dice handed out by an admin with a chosen perk is given anyway.

### dices

Configuration for all available dice effects. Each dice can be enabled/disabled and has specific settings.

### sounds

Sound played when using `!rtd`. Use sound file paths (e.g. `sounds/test.vsnd`) or sound events (e.g. `RollTheDice.Command`). Use `RollTheDice.{dice}` to play a sound event for each individual dice. Example audio files are provided via the AI from elevenlabs.io (Unreal Tonemanagement 2003).

- **dice_sound**: Sound path or event name to play. `{dice}`gets replaced by the case-sensitive dice name. Disabled if empty. A `sounds/...` path may only contain letters, digits and `_ - . /` (it is played with the client command `play`); other paths are ignored with a console message.
- **play_on_command_only**: Plays the sound only when a player types in `!rtd` - otherwise plays it on events as well.

### maps

Map-specific configuration overrides. Same structure as dice settings but only applies to specific maps.

### player_configs

Stores individual player settings automatically. Players are identified by SteamID64.


## Compile Yourself

Requires Docker. Clone and build with Make:

```bash
git clone https://github.com/Kandru/cs2-roll-the-dice.git
cd cs2-roll-the-dice
make restore
make debug    # development game server (uses OutputPath from the csproj when set)
make release  # production publish
make panorama # validate Panorama HUD sources
```
